Block theme for the OpenAustralia Foundation - a charity running public digital library services for democracy. Maroon institutional brand, full-site editing.

== Description ==

The OpenAustralia Foundation block theme powers oaf.org.au. It is a full-site-editing
(block) theme with the Foundation's maroon institutional brand, self-hosted fonts, and
custom blocks and patterns for the organisation's people, services, and donation pages.

This is a bespoke theme maintained for a single site and distributed through the Git Updater
plugin rather than the WordPress.org directory.
