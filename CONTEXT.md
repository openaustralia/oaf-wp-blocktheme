# OAF block theme

The WordPress block theme for oaf.org.au. These are the terms the theme uses for the pages it expects a site to have.

## Language

**Required page**:
A page the theme expects to exist on every site: home, blog and the seven pattern pages.
_Avoid_: Standard page, core page

**Pattern page**:
A required page whose body is a single reference to a registered theme pattern, and which brings its own hero.
_Avoid_: Marketing page, landing page

**Reconcile**:
Bring the required pages to the state the theme expects: create any that are missing, and replace a stale template on any that exist. Re-creating also overwrites a pattern page's content.
_Avoid_: Sync, seed, repair (as the name for the whole action)

**Stale template**:
A page template recorded on a page that the theme no longer provides, left over from the old classic theme.
_Avoid_: Legacy template, broken template
